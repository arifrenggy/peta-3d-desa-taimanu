# Peta 3D Desa Taimanu

Peta tiga dimensi untuk materi IPAS kelas 4 SD: **Wilayah Tempat Tinggalku** (buku IPAS kelas 4, Bab 3, halaman 65-78).

Buka langsung: https://arifrenggy.github.io/peta-3d-desa-taimanu/

Isi peta: gunung, hutan, sungai, danau, sawah, sekolah, masjid, balai desa, kantin, pasar, lapangan, jembatan, dan jalan.
Setiap tempat bisa diklik untuk membaca keterangan dan fakta singkatnya. Ada legenda, mata angin, skala, dan empat sudut pandang (bebas, utara, timur, dari atas).

Satu berkas HTML, seluruh pustaka dan font ikut di dalam berkas, jadi tetap jalan tanpa internet.
