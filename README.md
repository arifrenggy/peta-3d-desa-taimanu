# Peta 3D Desa Taimanu

Peta tiga dimensi untuk materi IPAS kelas 4 SD: **Wilayah Tempat Tinggalku** (buku IPAS kelas 4, Bab 3, halaman 65-78).

Buka langsung: https://arifrenggy.github.io/peta-3d-desa-taimanu/

## Dua mode

1. **Jelajah peta** (bawaan). Geser untuk memutar, scroll atau cubit untuk memperbesar, klik benda untuk membaca keterangan dan fakta singkatnya. Ada legenda tiga kategori, mata angin yang ikut berputar, skala 1 : 10.000, tombol tampil/sembunyikan nama, dan empat sudut pandang (bebas, utara, timur, dari atas).
2. **Uji kemampuan**. Untuk mengukur pemahaman siswa. 15 soal diambil acak dari 20 soal: pilihan ganda, benar atau salah, pilih simbol bergambar, dan klik benda di peta 3D. Bisa diisi nama siswa. Jawaban tidak langsung dinilai, jadi cocok untuk penilaian. Di akhir muncul nilai 0-100, predikat, bintang, rincian tiap soal beserta jawaban yang benar, serta tombol salin hasil untuk guru.

Isi peta: gunung, hutan, sungai, danau, sawah, sekolah, masjid, balai desa, kantin, pasar, lapangan, jembatan, dan jalan, ditambah rumah warga.

Satu berkas HTML. Seluruh pustaka dan font ikut di dalam berkas, jadi tetap jalan tanpa internet.
